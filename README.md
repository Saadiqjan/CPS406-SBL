# CPS406-SBL
A Product and Sprint Backlog Management System built for the Scrum development paradigm. This JavaFX application helps teams manage their product backlogs, plan sprints, track progress, and visualize sprint burndown charts.

Features:  
Product Backlog Management: Add, remove, and prioritize tasks for your project.  
Sprint Planning: Generate sprint backlogs automatically based on team capacity and task effort.  
Sprint Tracking: Monitor current sprint progress with interactive charts and progress bars.  
Burndown Charts: Visualize remaining effort over time to ensure sprint goals are met.  
Persistent Storage: All sprints and backlogs are saved locally for future reference.  
User-Friendly GUI: Built using JavaFX with intuitive controls and a clean layout.
